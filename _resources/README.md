# Übungsdateien zum Download

In diesem Ordner liegen die Word- und Excel-Dateien, die die Teilnehmenden über GitHub Pages herunterladen. Die Startseite der Website (`index.md`) und die Blockseiten im Grundkurs listen alles hier automatisch auf – eine Datei ablegen, committen, pushen, fertig.

## Ordner

| Ordner | Inhalt |
|---|---|
| `Grundkurs/Block-NN/` | Dateien eines Grundkurs-Blocks, `NN` zweistellig wie bei den Leitfäden (`Block-05`) |
| `Aufbau-Word/` | Dateien des Aufbaumoduls Word |
| `Aufbau-Excel/` | Dateien des Aufbaumoduls Excel |
| `Aufbau-Verknüpfung/` | Dateien des Aufbaumoduls Verknüpfung |
| `Materialien/` | Dateien zu den Nachschlagematerialien |

Die Ordnernamen müssen genau den Modulordnern im Repository entsprechen; die Liste der Module steht in `_config.yml` unter `module`.

## Dateien

- Erlaubt: `.docx`, `.dotx`, `.xlsx`, `.xltx`
- Namen: `Block-NN-Thema.docx` / `.xlsx`, das Übungsblatt `Block-NN-Uebungsblatt.docx`, Lösungen `Block-NN-Loesung-Thema.xlsx`; Aufbaumodule entsprechend mit dem Kürzel der Einheit
- Keine Leerzeichen und Umlaute im Dateinamen
- Dateien mit „Loesung“ im Namen werden auf der Seite als Lösung markiert
- Erzeugt mit den Skripten in `_werkzeuge/`; Regeln in `AGENTS.md` unter „Übungsblatt und Übungsdateien“
- Nur Szenario-Daten aus `00 Referenz Haus Lichtblick.md`, keine echten Personen oder Adressen

Die Seite ist öffentlich, Lösungen eingeschlossen.
